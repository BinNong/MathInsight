# Manim 数学动画生成功能设计方案

**日期**：2026-03-01

---

## 1. 功能概述

用户通过自然语言描述需求，后端使用 LLM 将描述转换为 Manim 代码，执行代码渲染生成 MP4 视频，返回下载链接。

**核心流程**：
```
用户描述 → LLM 生成代码 → 代码测试循环(≤10次) → Manim渲染 → 返回视频URL
```

---

## 2. 技术架构

### 2.1 系统组件

| 组件 | 职责 |
|------|------|
| LLM 适配器 | 多模型切换，支持 OpenAI/Claude/本地模型 |
| 代码生成器 | 描述 → Manim Python 代码 |
| 测试循环器 | 执行代码 + 检测错误 + 修复重试（≤10次） |
| Manim 渲染器 | 执行 manim 命令生成 MP4 |
| 文件服务 | 临时存储视频，提供下载 |

### 2.2 技术栈

- **后端**：Python Flask
- **LLM**：支持多模型切换（OpenAI/Claude/本地）
- **渲染**：Manim Community + FFmpeg
- **前端**：React + TypeScript

---

## 3. LLM Loop 机制

### 3.1 流程

```
第1次：LLM 生成 Manim 代码
    ↓
执行 manim -ql（低质量快速渲染）
    ↓
┌─ 成功 ──→ 返回视频URL
│
└─ 失败 ──→ 提取错误信息 → LLM 修复代码 → 第2次
                                            ↓
                                    ... (最多10次)
                                            ↓
                                    超过10次 → 返回错误提示
```

### 3.2 判定标准

- Manim 渲染成功无报错 = 正确
- 最大迭代次数：10次
- 失败提示："尝试多次仍失败，请简化描述"

---

## 4. API 设计

### 4.1 生成动画接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/manim/generate` | POST | 提交描述，返回视频URL |

**请求体**：
```json
{
  "description": "制作一个动画，展示单位圆如何被2x2矩阵[[1,1],[0,1]]变换成椭圆",
  "resolution": "720p",
  "fps": 30
}
```

**响应（成功）**：
```json
{
  "success": true,
  "video_url": "/downloads/manim_xxxx.mp4",
  "iterations": 3,
  "message": "生成成功"
}
```

**响应（失败）**：
```json
{
  "success": false,
  "error": "尝试多次仍失败，请简化描述",
  "iterations": 10
}
```
