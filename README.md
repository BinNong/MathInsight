## 快速开始

### 1. 配置环境变量

项目使用 `.env` 文件管理环境变量，**该文件不包含在版本控制中**。

进入 `backend` 目录，复制示例文件并填入实际密钥：

```bash
cd backend
cp .env.example .env
```

编辑 `.env` 文件，填入你的 LLM API 密钥（Manim 动画生成功能需要）：

- **Anthropic**（推荐）：配置 `ANTHROPIC_API_KEY` 和 `ANTHROPIC_BASE_URL`
- **OpenAI**：配置 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL`

> ⚠️ **注意**：`.env` 文件已加入 `.gitignore`，请勿将其提交到版本控制，避免 API 密钥泄露。

### 2. 安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### 3. 启动后端服务

```bash
cd backend
python run.py
```

后端服务运行在 http://localhost:5000

### 3. 安装前端依赖并启动

```bash
cd frontend
npm install
npm run dev
```

前端服务运行在 http://localhost:5173

## 功能模块

### MVP 功能

| 模块 | 功能 | 状态 |
|------|------|------|
| **ε-δ 极限可视化** | 动态展示函数在某点趋近过程，支持 ε-δ 定义可视化 | ✅ 已完成 (M1) |
| **导数切线可视化** | 实时绘制切线、法线，动态展示局部线性逼近，支持高阶导数与放大镜功能 | ✅ 已完成 (M2) |
| **矩阵变换可视化** | 2×2 矩阵对单位圆/网格的实时变换，支持特征向量和行列式显示 | ✅ 已完成 (M3) |
| **大数定律模拟** | 蒙特卡洛模拟演示样本均值收敛到期望值，支持抛硬币和掷骰子实验 | ✅ 已完成 (M4) |

### 已实现功能详情

#### M1: ε-δ 极限可视化
- 用户设定目标极限值 L 和 ε 范围
- 系统自动计算满足条件的 δ 区间
- 双色带高亮 |x−x₀|<δ 与 |f(x)−L|<ε 区域
- 支持自定义函数表达式（如 `x**2`, `sin(x)` 等）
- 可调节 x₀ 位置观察逼近过程

#### M2: 导数增强功能
- **切线/法线可视化**：实时绘制切线和法线
- **局部线性近似**：展示 f(x) 与 L(x) = f(x₀) + f'(x₀)(x−x₀) 的对比曲线
- **误差区域着色**：直观显示函数与切线的误差
- **高阶导数显示**：可切换 f, f', f'', f''' 曲线
- **放大镜功能**：局部无限放大后观察曲线趋近直线
- 支持三角函数（sin, cos, tan）、指数（exp）、对数（log, ln）等表达式

#### M3: 矩阵变换可视化
- **2×2 矩阵输入**：支持数字输入框和滑块调节
- **实时变换动画**：观察单位圆→椭圆、网格变形过程
- **预设矩阵模板**：单位、缩放、旋转、剪切、反射等常用变换
- **特征向量显示**：可视化特征方向在变换中的不变性
- **行列式信息**：显示面积缩放比例和变换方向
- **基向量追踪**：显示 e₁ 和 e₂ 变换后的位置

#### M4: 大数定律模拟
- **蒙特卡洛实验**：支持抛硬币（伯努利分布）和掷骰子（离散均匀分布）
- **实时动画**：模拟过程可视化，正面/反面或骰子点数动态展示
- **收敛曲线**：绘制样本均值随样本量增加向期望值收敛的过程
- **分布直方图**：实时显示样本结果的频率分布
- **预设模板**：公平硬币、偏心硬币、标准骰子、自定义骰子
- **参数可调**：样本数量、动画速度可自由配置

## 技术栈

- **前端**：React + TypeScript + Plotly.js
- **后端**：Flask + SymPy + NumPy
